# Solidity 算法与投票系统示例

本目录包含 6 个 Solidity 合约示例，涵盖常见算法实现和投票系统：

## 算法合约

### 1. [BinarySearch.sol](BinarySearch.sol)
- **功能**：在有序 `uint` 数组中使用二分查找法查找目标值
- **特点**：
  - 防溢出的中间值计算
  - 返回索引或 `-1`（未找到）
  - 纯函数（`pure`）

### 2. [IntegerToRoman.sol](IntegerToRoman.sol)
- **功能**：将整数（1-3999）转换为罗马数字字符串
- **特点**：
  - 输入范围限制
  - 使用数值-符号映射表
  - 动态构建结果字符串

### 3. [MergeSortedArray.sol](MergeSortedArray.sol)
- **功能**：合并两个已排序的 `uint` 数组（升序）
- **特点**：
  - 输入验证（非空数组）
  - 双指针合并算法
  - 处理剩余元素

### 4. [ReverseString.sol](ReverseString.sol)
- **功能**：反转输入字符串
- **特点**：
  - 使用 `bytes` 操作实现
  - 输入验证（非空字符串）
  - 纯函数（`pure`）

### 5. [RomanToInteger.sol](RomanToInteger.sol)
- **功能**：将罗马数字字符串转换为整数
- **特点**：
  - 支持减法规则（如 IV=4, IX=9）
  - 逐字符解析
  - 错误处理

## 应用合约

### 6. [Voting.sol](Voting.sol)
- **功能**：简单投票系统
- **特点**：
  - 防重复投票
  - 候选人得票统计
  - 数据重置功能
- **存储结构**：
  - 映射：候选人得票记录、投票人记录
  - 数组：候选人列表、投票人地址列表

## 使用说明
- 所有合约使用 Solidity 0.8.0+ 编译
- 纯函数（`pure`）无需部署即可测试
- 状态修改函数（如投票系统）需部署后使用

## 安全注意事项
- `Voting.sol` 中的 `resetVotes` 为公开函数，生产环境应添加访问控制（如 `onlyOwner`）
- 算法合约仅为示例，实际应用需考虑 gas 成本
- 输入验证：所有合约均包含基本输入验证
